Documentation

Everything about Agent Fishtank: getting it running, what the tank shows, every setting, and what to do when something doesn't work.

Install

You need Claude Code and/or GitHub Copilot CLI. Nothing else, not even Node.js. Get the installer for your computer from the latest release:

Your computerDownload
Mac with Apple Silicon (M1 or newer)Agent-Fishtank-arm64.dmg
Mac with IntelAgent-Fishtank-x64.dmg
Windows (also runs on Arm)Agent-Fishtank-Setup.exe

On a Mac

  1. Open the .dmg and drag Agent Fishtank into Applications.
  2. Open it from Applications. Because the app isn't signed by Apple yet, macOS blocks it the first time. Go to System Settings → Privacy & Security, scroll down to the message about Agent Fishtank and click Open Anyway. (Or run xattr -dr com.apple.quarantine "/Applications/Agent Fishtank.app" in Terminal.)

On Windows

  1. Run the installer. The app isn't signed yet, so Windows SmartScreen may warn you: click More info → Run anyway.
  2. Agent Fishtank opens when the installer is done.

Build it yourself

You need Git and Node.js 22.18 or newer.

git clone https://github.com/VinnieVH/agents-fishtank.git
cd agents-fishtank
npm ci
npm run dist

This takes a few minutes and puts the installers in the release folder.

Connect to your agents

The first time Agent Fishtank starts, it asks to connect to the agents it finds on your computer. Click Connect.

From then on the fishtank opens by itself when you start a session and closes after the last one ends. You can close the window any time; it comes back with your next session. Prefer it to stay open, or to start with your computer? See Settings.

To connect or disconnect later, use the menu: Agent Fishtank in the menu bar on a Mac, the File menu on Windows (press Alt if you don't see it).

What does connecting change?

Claude Code: adds hooks to ~/.claude/settings.json that start the app and tell it what your sessions are doing, and wraps your status line so the app learns your plan usage. Your own hooks and status line keep working as before. A backup is kept as settings.json.fishtank-backup, and nothing is changed if the file isn't valid JSON.

Copilot CLI: adds one hook file, ~/.copilot/hooks/fishtank.json, that starts the app.

Disconnecting removes exactly these again and puts your own status line back.

Updates

Agent Fishtank checks for a new version when it starts and every few hours. When one is out, it asks you whether to Download it, do it Later, or Skip This Version.

Download opens the installer for your computer. Quit Agent Fishtank, then install it like the first time: on a Mac drag it into Applications and replace the old one, on Windows run the installer. Your connection and settings stay as they are. You can also check yourself with Check for Updates… in the menu. See what's new in each version.

The check is a single request to GitHub's public release list. To turn it off, set FISHTANK_NO_UPDATE_CHECK=1.

Uninstall

On a Mac: first choose Disconnect in the Agent Fishtank menu (for each agent), then drag the app to the Trash. If you skip the disconnect, Claude Code keeps calling the removed app and shows hook errors; reinstall and disconnect, or remove the fishtank entries from ~/.claude/settings.json.

On Windows: uninstall it in Settings → Apps. The uninstaller disconnects it for you.

Each fish is named after its session: the name you gave it, Claude Code's title for it, or the start of your first prompt. Sessions get different creatures and glow colours, so no two look alike (meet them all).

Click a fish to jump to its session: the Claude desktop app opens it, iTerm or Terminal switches to its tab (other terminals and editors come to the front), and a Copilot session that has ended is resumed in a new terminal window. If you switched a Copilot CLI to another session with /resume, clicking the old session's fish brings that CLI to the front. On a Mac, the first click asks to let Agent Fishtank control iTerm or Terminal; allow it (or later in System Settings → Privacy & Security → Automation).

And just for fun: the water follows the real time of day (with glowing plankton at night), a whale, an orca, a shark, a pod of dolphins, a manta ray or a school of jellyfish drifts by now and then (and once in a while something rarer), a crab comes out when everything is quiet, and you can click the water to feed the fish.

Built-in terminals

The app has terminals of its own: click the terminal button in the panel (or press Ctrl+\, ⌘\ on a Mac) and they open on the left, with the tank on the right.

  • The + starts Claude Code, Copilot CLI or a plain shell (PowerShell on Windows, your login shell on a Mac) in a tab, in the folder shown under it.
  • Drag the edge between the terminals and the tank to share the window.
  • A CLI that ends leaves you in the shell.
  • Copy with Ctrl+C while text is selected (⌘C), paste with Ctrl+V (⌘V) or a right click, and switch tabs with Ctrl+Tab.
  • The app asks before quitting while terminals are open, and doesn't quit by itself while they are.

Seasons

Every year the tank dresses up for a handful of festive seasons: the fish get a hat, a garland goes up across the top and things drift through the water. A season starts and ends on the same days every year, and the tank switches over by itself (by your computer's date; the first and last day both count). Where two seasons overlap (Lunar New Year and Valentine's share 8 – 16 February), the later one in the list wins. Outside the dates the tank looks normal.

Winter is the first with a full makeover: the sand turns to snow, with a big Christmas tree surrounded by gifts, a snowman and the chest half buried in a snowdrift. The sea-floor decorations of the other seasons are still being fine-tuned. This website joins in too, so far for the winter holidays, with falling snow and a string of lights.

Turn it off in Settings (Decorate the tank for festive seasons), or preview a season with ?season=<id> on the tank's address, for example ?season=halloween.

Notifications don't appear while the fishtank window is in front, and clicking one opens the tank. On a Mac, allow them the first time macOS asks (or later in System Settings → Notifications → Agent Fishtank).

Watching from other devices

With Let other devices on my Wi-Fi watch the tank on, the settings show a QR code and an address (port 4322, with a secret key). Scan the code or open the address in a browser on your phone, tablet or another computer on the same network.

On a TV, open the short address the settings show (like 192.168.1.20:4322) and type the 6-digit code from the settings. The device remembers it after that.

Other devices can only watch: they can't open sessions, change settings or use the terminals. Windows may ask once to allow Agent Fishtank through the firewall on private networks.

Troubleshooting

The air tanks don't show up

They need a Claude Pro or Max subscription, and appear after your first Claude reply in a terminal session. If an ANTHROPIC_API_KEY is set in your environment, Claude Code uses that instead of your subscription, and there's no plan usage to show. The Claude desktop app doesn't send usage either, so the tanks keep the last numbers from a terminal session.

Claude Code shows "hook error" notices

The app isn't running or was removed. Start Agent Fishtank, or disconnect it from the menu (see Uninstall).

"Port 4321 is already in use."

Another fishtank is running, often the old browser version. Close it (or restart your computer) and open Agent Fishtank again.

macOS says the app can't be opened, or Windows shows a SmartScreen warning

The app isn't signed yet; see Install for the one-time step.

A session's fish doesn't show up

The tank shows sessions that were active in the last hour. Check that the agent is connected (the menu says Disconnect from … when it is). A new Claude Code session gets its fish with your first message (a session you've only opened isn't shown yet); a Copilot session as soon as it writes to its log.

Privacy

Everything stays on your computer. The app only listens on 127.0.0.1, reads your agents' local session files, and never answers your agents' hooks with anything but an empty "OK", so it can't change what they do. The only thing it sends over the internet is the update check to GitHub.

If you turn on sharing, the app also answers on your local network, but only to show the tank, and only to a browser that has the secret key: from the address (or its QR code), or by typing the 6-digit code shown in the settings, which only works once, changes every few minutes and stops taking tries for a minute after five wrong ones. Anyone with the key sees your session names and prompts, so share it only with people who may. The key stays the same between restarts; it's kept in agent-fishtank-share-key in the app's data folder (delete it to get a new one).
