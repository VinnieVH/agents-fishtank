A little aquarium on your desktop that shows what your AI coding agents are doing. Every Claude Code or GitHub Copilot CLI session is a fish.

Each fish is named after its session; click one to jump to its session, in the Claude desktop app or in its terminal tab. The water follows the real time of day, with glowing plankton at night, a whale or shark drifts by now and then, and you can click the water to feed the fish.

Up and running in a minute

  1. Install

    Mac: open the .dmg and drag Agent Fishtank into Applications. Windows: run the installer. No Node.js or anything else needed.

  2. Connect

    On first start it offers to connect to the agents it finds. Click Connect. Your own Claude Code hooks and status line keep working.

  3. Start a session

    The fishtank opens by itself when you start a session, and closes after the last one. Prefer it differently? The gear in the panel has the settings. New versions are offered automatically.

Good to know

macOS says the app can't be opened

The app isn't signed by Apple yet. The first time, go to System Settings → Privacy & Security, scroll down to the message about Agent Fishtank and click Open Anyway.

Windows shows a SmartScreen warning

The installer isn't signed yet. Click More info → Run anyway.

What can I change in the settings?

Click the gear in the panel. You can get a notification when a session needs you or is done (only after it has waited a while, so not for the session you're working in), keep the tank always day or night, make the animation calmer, turn off the whale and shark, keep the fishtank running after your sessions, or start it in the background when you log in.

The air tanks don't show up

They need a Claude Pro or Max subscription and appear after your first Claude reply in a terminal session. With an ANTHROPIC_API_KEY set, Claude Code uses that instead and has no plan usage to show.

Does it send my code anywhere?

No. It only reads your agents' local session files and listens on 127.0.0.1. It never changes what your agents do. The only internet request is the check for new versions on GitHub.

How do I uninstall it?

Mac: choose Disconnect in the Agent Fishtank menu, then drag the app to the Trash. Windows: uninstall it in Settings → Apps; that disconnects it for you.
